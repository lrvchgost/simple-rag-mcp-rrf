Заметки по деплою AuthService (не для новичков).

Перед выкаткой новой версии обязательно прогнать миграции Redis: скрипт
scripts/migrate_sessions.py переименовывает старые ключи сессий в новый формат
session:<user_id>:<device_id>. Без миграции часть пользователей вылетит из аккаунтов.

Канареечный релиз: 10% трафика на 30 минут, смотрим метрику login_failure_rate.
Если выше 0.5% — откатываем через helm rollback auth-service.

Токен TOKEN_EXPIRY_HOURS читается из auth_settings.yaml сервисом TokenService
при старте. Менять его на лету нельзя, только через рестарт с новым конфигом.

Память: контейнеру auth-service нужно минимум 512 Mi, иначе OOM при пиках входов
в понедельник утром.
